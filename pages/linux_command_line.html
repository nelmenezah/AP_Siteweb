Les commandes de base Linux

Voici les commandes à connaître pour naviguer, gérer des fichiers et administrer un système Linux en ligne de commande. Elles sont classées par thème.

Astuce : en cas de doute sur une commande, tape man nom_de_la_commande pour afficher son manuel (quitte avec la touche q).

Se déplacer

Commande Description Exemple
pwd Affiche le chemin du dossier où tu te trouves (Print Working Directory). pwd
ls Liste les fichiers et dossiers. L'option -la affiche aussi les fichiers cachés et les détails. ls -la
cd Change de dossier (Change Directory). cd .. remonte d'un niveau, cd seul revient au dossier personnel. cd /home/utilisateur
clear Efface l'écran du terminal. clear

Gérer les fichiers et dossiers

Commande Description Exemple
mkdir Crée un nouveau dossier (Make Directory). mkdir nouveau_dossier
touch Crée un fichier vide. touch fichier.txt
cp Copie un fichier. Ajoute -r pour copier un dossier. cp fichier.txt copie.txt
mv Déplace ou renomme un fichier ou un dossier. mv ancien_nom.txt nouveau_nom.txt
rm Attention Supprime un fichier (Remove). Il n'y a pas de corbeille : c'est définitif ! Ajoute -r pour un dossier. rm mon_fichier.txt
cat Affiche le contenu d'un fichier dans le terminal. cat fichier.txt
nano Ouvre un éditeur de texte simple dans le terminal (Ctrl+O pour enregistrer, Ctrl+X pour quitter). nano fichier.txt

Chercher

Commande Description Exemple
grep Cherche un mot ou une phrase à l'intérieur d'un fichier. grep "erreur" journal.log
find Cherche un fichier par son nom dans un dossier et ses sous-dossiers. find /home -name "notes.txt"

Utilisateurs et système

Commande Description Exemple
whoami Affiche le nom de l'utilisateur connecté. whoami
sudo Exécute une commande avec les droits administrateur. sudo apt update
apt Installe, met à jour ou supprime des logiciels (Debian, Ubuntu). sudo apt install apache2
chmod Modifie les droits d'accès d'un fichier (lecture, écriture, exécution). chmod 755 script.sh
ps Affiche les processus en cours d'exécution. ps aux
systemctl Démarre, arrête ou vérifie l'état d'un service. systemctl status apache2

Réseau

Commande Description Exemple
ip a Affiche les interfaces réseau et les adresses IP de la machine. ip a
ping Teste si une machine ou un site répond sur le réseau. -c 4 envoie 4 paquets seulement. ping -c 4 google.fr
ssh Se connecte à une machine distante en ligne de commande. ssh utilisateur@192.168.1.10
